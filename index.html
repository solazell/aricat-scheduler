⏰ตารางโพสต์ & AI

🤖 Anthropic API Key คืออะไร / ใช้ยังไง

ถ้าใส่คีย์นี้ ปุ่ม 🪄 จะให้ Claude (AI) ดูรูปที่แต่งแล้ว แล้วเขียนแคปชั่นไทย-อังกฤษและแฮชแท็กให้ใหม่ทุกครั้ง ตรงกับอารมณ์ที่เลือก ถ้าเว้นว่าง แอปจะสุ่มจากคลังแคปชั่นสำเร็จรูปแทน (ใช้งานได้ปกติ ไม่เสียเงิน)

  1. เข้า platform.claude.com (Claude Console) แล้วสมัคร/ล็อกอิน
  2. ไปที่ Billing เติมเครดิต (ต้องเติมก่อน ไม่งั้นคีย์ใช้ไม่ได้)
  3. ไปที่ API keys → Create Key ตั้งชื่อ แล้วคัดลอกคีย์ (ขึ้นต้น sk-ant-) เก็บไว้ เพราะจะแสดงครั้งเดียว
  4. วางในช่องด้านบนแล้วกด บันทึกการตั้งค่า

⚠️ บัญชี claude.ai (แชท/Pro/Max) แยกจาก API ไม่ใช้เครดิตร่วมกัน • คีย์เก็บในอุปกรณ์นี้เท่านั้น อย่าแชร์หรือแคปหน้าจอให้ใคร • ค่าใช้จ่ายต่อแคปชั่นน้อยมาก ดูราคาจริงและยอดใช้งานได้ใน Console
